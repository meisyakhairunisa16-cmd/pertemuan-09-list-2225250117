## Tujuan
Mempelajari penggunaan list Python untuk menyimpan, memanipulasi, dan mengolah data numerik.

## Struktur Program
- `01_buat_list.py`: membuat dan membaca list.
- `02_indeks_slicing.py`: mengakses elemen dengan indeks dan slicing.
- `03_manipulasi_list.py`: mengubah, menambah, menyisipkan, dan menghapus elemen.
- `04_agregasi_nilai.py`: menghitung statistik nilai.
- `05_filter_kelulusan.py`: menyaring nilai kelulusan.
- `06_fungsi_statistik.py`: menghitung rata-rata menggunakan fungsi.
- `analisis_nilai_mahasiswa.py`: menganalisis nilai dan kelulusan mahasiswa.

## Cara Menjalankan
Jalankan melalui terminal VS Code:

`python latihan/01_buat_list.py`

Ganti nama file sesuai program yang ingin dijalankan.

## Test Case
1. Data `[60, 70, 80]` menghasilkan rata-rata 70.00.
2. Nilai minimum adalah 60 dan maksimum adalah 80.
3. Ketiga nilai dinyatakan lulus dengan batas kelulusan 60.
4. Data `[59, 60, 61]` menghasilkan dua nilai lulus.
5. List kosong pada fungsi rata-rata menghasilkan 0 tanpa error.
